# C++ Practice Programs — Semester 2 (COMP 116)
This repository contains C++ programs written during my second semester as part of **COMP 116 – Object-Oriented Programming in C++** at Kathmandu University. It covers core OOP concepts along with general C++ practice programs.

## Concepts Covered
- **Classes & Objects** – basic class design, constructors, destructors
- **Encapsulation** – access specifiers, getters/setters
- **Operator Overloading** – overloading `+`, `-`, `==`, etc. (e.g. `Time.cpp`, `Timeadd.h`)
- **Inheritance** – single and multilevel inheritance
- **Polymorphism** – runtime polymorphism using virtual functions (e.g. `College_Management.cpp`)
- **Abstraction** – abstract classes and interfaces
- **Real-world Simulation** – e.g. `BankManagement.cpp`, `account.cpp`

## Tools Used 
- Language:C++
- Compiler:g++ / MinGW
- IDE:Visual Studio Code
